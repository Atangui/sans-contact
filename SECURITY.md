# Sécurité

SansContact pilote la souris et utilise la caméra : une faille peut toucher la vie privée.

## Signaler une faille

Merci de **ne pas** ouvrir de ticket public. Utilisez le signalement privé de GitHub
(onglet « Security » du dépôt › « Report a vulnerability »). Décrivez le problème, la version,
et si possible les étapes pour le reproduire. N'envoyez jamais d'image de caméra ni de capture d'écran
montrant une personne.

## Ce qui compte comme une faille

- Toute connexion réseau, tout port ouvert, toute écriture d'image sur disque.
- Une caméra allumée sans action de l'utilisateur, ou qui reste allumée après désactivation ou verrouillage.
- Une injection de souris ou de clavier qui échappe à la machine d'états ou au raccourci d'arrêt.
- Un bouton de souris qui reste enfoncé.
